# WT — Plain HTML/CSS/JavaScript Frontend

This is a frontend-only prototype for the Kenyan short-term lending platform **WT**.

## WT visual theme
The frontend uses a professional **green + blue + black accent** palette: green for primary actions, blue for supporting highlights, and black/dark charcoal for navigation and contrast.

## No framework
- HTML5
- CSS3
- Vanilla JavaScript
- SVG logo
- No React
- No Vite
- No npm
- No Node.js required

## Run
Open `index.html` directly in a browser, or use VS Code Live Server.

## Pages
- index.html — public landing page
- register.html — applicant registration/onboarding
- login.html — applicant login
- dashboard.html — applicant dashboard
- apply-loan.html — loan application
- loan-status.html — loan status and repayment
- profile.html — applicant profile
- admin.html — owner/admin UI

## Important
All authentication, identity verification, authorization, loan calculations, document storage, approvals, audit logs and payment processing must be implemented securely on the backend. The displayed values are demo data only.
